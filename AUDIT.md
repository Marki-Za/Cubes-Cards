# Аудит віджета «Збери свій набір»

| Проблема | Рівень критичності | Причина | Рекомендація |
|---|---|---|---|
| Браузерні сценарії не запускались у поточному середовищі | Середній | Консоль не має доступної команди Node.js; Playwright/браузерний інструмент не використовувався для автоматичних перевірок | Запустити вручну в Chrome та перевірити 320/375/768/1024/1280/1440 px |
| Node-тести не мають реального фактичного підсумку | Середній | Node.js не розпізнається оболонкою | Встановити Node.js або відкрити проєкт в середовищі, де Node доступний, і виконати `node tests/widget.test.js` |
| Два однакові корені потребують унікальних id елементів | Низький | Поточна розмітка має зручні статичні id, хоча логіка ініціалізується відносно кореня | Для справжнього повторення екземпляра клонувати й унікально перейменувати всі id/aria посилання |
| Логіка недоступна до завантаження DOM | Низький | Ініціалізація прив'язана до DOMContentLoaded | Залишити завантаження скрипта наприкінці сторінки та не викликати init поза try/catch |
| Клавіатура та реальний фокус потребують перевірки браузером | Середній | Статичного аналізу недостатньо для перевірки Tab/Shift+Tab і фокуса | Перевірити ручну навігацію з клавіатури, ring та повернення фокуса |

Під час аудиту перевірено: IIFE, чисті validate/calculate, події addEventListener, textContent замість innerHTML, aria-invalid/aria-describedby, mobile-first Tailwind-класи та відсутність змін у логіці попередніх плагінів.
