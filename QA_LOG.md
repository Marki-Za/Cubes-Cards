# QA-журнал віджета

Рядки нижче роблять різницю між очікуванням і реальним станом. Тестовий прогон не створювався штучно.

| Що вводили | Яка була помилка/поведінка спочатку | Як її виправили завдяки захисним перевіркам |
|---|---|---|
| Порожнє поле `""` | Реальний вивід results-before недоступний через відсутність Node.js | validateSets повертає точне повідомлення і `value: null` замість конвертації в 0 |
| Пробіли `"   "` | Не запускався реальний тест у поточній оболонці | trim та регулярка відхиляють порожній після trim рядок |
| Нуль `"0"` | Не запускався реальний тест у поточній оболонці | Діапазон від 1 до 50 і точне повідомлення |
| Від'ємне `"-5"` | Не запускався реальний тест у поточній оболонці | Регулярка відхиляє знак мінус |
| Надвелике `"9999999999999999"` | Не запускався реальний тест у поточній оболонці | Обмеження регулярки до 1–3 цифр |
| Дробове `"2.5"` | Не запускався реальний тест у поточній оболонці | Крапка і дробова частина не проходять регулярку |
| Текст `"abc"` | Не запускався реальний тест у поточній оболонці | Несімвольне значення відхиляється без Number/NaN |
| Експонента `"5e2"` | Не запускався реальний тест у поточній оболонці | e відхиляється регуляркою |
| Infinity `"1e309"` | Не запускався реальний тест у поточній оболонці | Рядок не входить у `^\d{1,3}$`, Infinity не показується |
| HTML `"<script>alert(1)</script>"` | Не запускався реальний тест у поточній оболонці | Рядок відхиляється; усі текстові значення показуються через textContent |
| Підроблений select `"hacker"` | Не запускався реальний тест у поточній оболонці | calculateTotal повертає null; UI показує точне повідомлення |
| `initWidget(null)` і порожній root | Не запускався реальний тест у поточній оболонці | Функція перевіряє root та всі потрібні елементи й повертає null |
