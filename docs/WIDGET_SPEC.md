# Специфікація віджета «Збери свій набір»

## Бізнес-правила

| Параметр | Тип | Значення | Вплив |
|---|---|---|---|
| Кількість наборів | number | ціле 1–50 | 450 грн за набір |
| Тип набору | select | classic / premium / collector | 0 / 600 / 1500 грн |
| Подарункова упаковка | checkbox | увімкнено/вимкнено | 250 грн |
| Гравіювання | checkbox | увімкнено/вимкнено | 400 грн |
| Експрес-доставка | checkbox | увімкнено/вимкнено | 300 грн |

Базова вартість: 200 грн.

Формула: `200 + sets * 450 + typeFee + giftBox(250) + engraving(400) + express(300)`.

## Еталонні результати

| Вхід | Результат |
|---|---:|
| 1 набір, classic, опції вимкнені | 650 грн |
| 5 наборів, premium, упаковка та гравіювання | 3700 грн |
| 50 наборів, collector, усі опції | 25150 грн |

## Події та валідація

- `input` для кількості миттєво перераховує результат.
- `change` для select і checkbox миттєво перераховує результат.
- `click` для Скинути повертає `1`, `classic` і вимкнені опції.
- `click` для Замовити показує демо-повідомлення та тимчасово блокує повторну дію на 1500 мс.
- Кількість очищується через `trim`, перевіряється регуляркою `^\d{1,3}$`, потім перевіряється діапазон 1–50.
- Текст помилки кількості: `Введіть кількість наборів — ціле число від 1 до 50.`
- Підроблений тип: `Оберіть тип набору зі списку.`
