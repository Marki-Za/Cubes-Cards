# Журнал етапів ЛР №5

| Етап | Промпт-завдання | Результат | Що скориговано |
|---|---|---|---|
| A — div-каркас | Створити початкову сторінку переважно на `<div>` з базовими метаданими й мінімальним CSS. | `stages/01-div-soup/index.html` і `style.css`: показовий каркас hero, переваг, кроків і квізу. | Додано адаптивний перехід на вузький екран; несемантичність збережено навмисно для порівняння. |
| B — семантика | Замінити безіменні блоки семантичними елементами, додати навігацію, заголовки, списки, статті та форму. | Створено `stages/02-semantic/index.html` та фінальний `index.html`; є один `main`, один `h1`, логічні `h2`/`h3`, labels і skip link. | Кнопки переходу оформлено як посилання, бо вони навігують до секцій; інтерактивний квіз залишено статичним. |
| C — CSS-архітектура | Зберегти навчальний CSS «до», а у фінальній версії застосувати токени, Grid/Flexbox та адаптивність. | `stages/03-css-before-refactor/style.css` та `css/style.css`. | Токени згруповано за призначенням; картки мають Grid, навігація й кнопки — Flexbox. |
| D — активи | Підключити локальні логотип, іконки, зображення та hero-відео з робочими шляхами. | SVG та WebP збережені у `assets/icons`/`assets/images`; відео скопійовано до `assets/video/hero-video.mp4`. | Для темного header створено прозору контрастну версію вихідного логотипа, оригінал не змінено. | E — CSS Refactoring Guard | Знайти дублювання, невикористані класи та надмірну специфічність; винести повтори в custom properties. | Фінальний CSS організовано за компонентами, значення кольорів, типографіки, відступів, радіусів, тіней і переходів — у `:root`. | Перевірка коду: повтори дизайн-токенів усунені; надмірної специфічності немає; стилі проміжного етапу ізольовані від фінальної таблиці стилів. |
| F — доступність | Перевірити семантику, alt, форму, фокус, контраст, клавіатурну навігацію й ARIA. | Skip link, видимий focus, текстові labels, змістовна ієрархія заголовків, aria-label лише там, де потрібно. | Кружечки кроків використовують темний текст на жовтому/м’ятному/кораловому тлі; декоративні SVG мають порожній alt. |
| G — самоперевірка | Перевірити HTML, ідентифікатори, кількість main/h1, шляхи активів і відкриття локально. | Проведено локальну перевірку розмітки та шляхів скриптом; структура перевірена за чек-листом HTML. | Зовнішній HTML-валідатор у цьому проєкті не підключався, сторонні залежності не встановлювалися. |
| H — документація | Задокументувати результати етапів, припущення й майбутні компоненти ЛР №6. | Створено цей журнал і `NOTES.md`. | Окремо зазначено тестовий характер контактів/відгуків, обмеження статичного демо та наступні кроки. |

## Звіт Refactoring Guard (етап E)

| Перевірка | Результат |
|---|---|
| Повторювані значення | Основні кольори, типографічна шкала, відступи, радіуси, тіні та переходи централізовано у `:root`. |
| Повторювані відступи/радіуси | Застосовано шкалу `--space-*`, `--radius-*`; структурні розміри сіток залишені в компонентах. |
| Невикористані класи | У фінальному CSS селектори зіставлені з фінальним HTML; CSS проміжних етапів не підключається. |
| Надмірна специфічність | Використано прості BEM-селектори; `!important` відсутній. |
| Порядок стилів | Правила згруповані за reset/tokens, базовими компонентами, секціями та адаптивністю. |

## Таблиця аудиту доступності (етап F)

| Проблема | Причина | Виправлення |
|---|---|---|
| Користувач клавіатури мав би проходити всю навігацію до контенту | Не було швидкого переходу до основного вмісту | Додано skip link, який з’являється у фокусі. |
| Герой містить відео без альтернативного тексту | Відео без елементів керування використовується як декор | Відео приховане від AT, але його fallback-текст та прихований опис пояснюють візуальний зміст; для reduced motion відео вимикається. |
| Кнопки всередині hero можуть мати недостатню помітність фокуса | Стандартний індикатор браузера нестабільний між платформами | Додано глобальний контрастний `:focus-visible` з відступом. |
| Кольорові номери кроків могли використовувати білий текст із низьким контрастом | Світлі насичені фони не гарантують достатній контраст білого | Для номерів задано темний текст `--color-ink`; самі цифри декоративно приховані від повторного озвучення. |
| Кораловий текст на кремовому тлі мав контраст нижче WCAG AA | Початковий `#FF6B5A` призначений для заливок/акцентів, а не дрібного тексту | Додано окремий `--color-coral-text` (`#B02E24`) для малих підписів; яскравий кораловий залишено для графічних акцентів. Загальне hover-фарбування прибране, щоб контентні посилання на світлому тлі не втрачали контраст. |
| Контактні поля могли не мати програмного імені | Placeholder не замінює label | У кожного поля є видимий пов’язаний `<label>`, `required` та відповідний тип email. |
