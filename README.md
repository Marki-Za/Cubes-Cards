# Кубики&Карти

Статичний сайт підписки на бокси настільних ігор. Сторінки публікуються без build-команди; корінь проєкту містить `index.html`.

## Деплой на Netlify

### Netlify Drop

1. Відкрийте [Netlify Drop](https://app.netlify.com/drop).
2. Перетягніть папку проєкту з `index.html`, `assets/`, `css/` та `js/` у вікно завантаження.
3. Дочекайтеся публікації сайту та за бажанням налаштуйте власну назву сайту.

### Через GitHub

1. Завантажте проєкт у GitHub.
2. У Netlify оберіть **Add new site → Import an existing project** та під’єднайте репозиторій.
3. Залиште команду build порожньою; publish directory — `.` (також задано в `netlify.toml`).
4. Натисніть **Deploy site**.
